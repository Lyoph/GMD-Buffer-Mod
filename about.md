## Input Buffer

Makes tight timings easier by remembering clicks that you hit too early!

## What it does

- **Cube, Ball, Robot, Spider:** tap slightly before landing or before an orb, release, and the click fires the moment you touch the surface or ring.
- **Ship, UFO, Swing:** very short taps are stretched to a minimum length so quick inputs come out consistent.
- **Wave:** choose between three styles: Min Hold, Min Gap or Grid snap.
- **2 Player:** both icons are buffered using the same rules.
- **Dual portal (experimental):** off by default. Turn it on in the settings to buffer each icon by its own mode.

## Settings

Open them from Geode's mod list, or press the **Buffer** button on the pause menu. Use the **Profiles** button to save settings under a name and link a profile to a level, so it applies automatically when that level loads and your own settings come back when you leave. Default hotkeys while in a level (rebindable in the settings):

- **F6** cycle the buffer window
- **F7 / F8** TPS up / down
- **F9** debug logging
- **F10** wave mode

Type the TPS option to match the TPS you use in your other tools, or the buffer window will be the wrong size.

## Note

This is an input assist. Use it for practice and fun, not for leaderboard or submitted runs.

**Level sections (experimental):** switch to a different profile at chosen percents of a level. Set them in Pause > Profiles > Sections.
